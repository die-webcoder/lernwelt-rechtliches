# Lernwelt – Rechtstexte

Öffentliche Rechtstexte der Lern-App **Lernwelt** (Impressum, Datenschutzerklärung, Nutzungsbedingungen, Lizenzen).
Die Seiten werden über GitHub Pages veröffentlicht und im Google Play Store verlinkt.

Die Texte werden nicht hier bearbeitet, sondern im App-Repository erzeugt (`scripts/export-legal.mjs`),
damit sie wortgleich mit den Texten in der App sind.
